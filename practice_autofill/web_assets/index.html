A LITTLE GUIDANCE

开始前，看这里。

只用于你有权访问、允许自动化及 AI 辅助的练习或自测页面。

01

先选择浏览器

已有带调试端口的 Chrome / Edge：选择连接模式，填写本机 CDP 地址。普通窗口无法直接附加。

没有调试窗口：选择启动新实例，输入页面地址，手动登录。工具使用独立资料目录复用登录。

02

配置模型，再开始

API Key 从环境变量读取，也能在页面隐藏输入。Key 不会回显，不会写入文件；关闭控制台后本次修改失效。

先运行本地演练，可以不配置 Key、不产生真实模型请求，熟悉提取与回填流程。

03

在交互区回应提示

完成手动登录后，按提示发送空回复继续。有多个标签页时，输入题目页对应编号。

开启逐题确认时，输入 y 回填、其余跳过。处理后可人工翻页，再输入 r 扫描；工具不会自动翻页。

04

停止与恢复

停止会在安全检查点结束；正在等待的模型请求可能要等到返回或超时。已写入的内容不会自动撤销。

重新开始会复用已校验缓存，并核对网页状态。缓存、日志和专用登录资料保存在项目 runtime/。

能力边界

支持结构明确的单选、多选和文本填空，包括可识别的 contenteditable 与可访问 iframe。图片题、未知归属控件和复杂编辑器转人工；通用规则不保证适配任意网站。

超星使用独立适配器和本地选择器配置。遇到登录、验证码或访问限制，请在浏览器手动处理，工具不会尝试绕过。

原命令行入口保留：Start.cmd --menu。网页与终端分别启动时，临时配置和任务各自独立；不要同时操作同一答题页面。
