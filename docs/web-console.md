# 网页控制台

## 启动方式

在项目目录运行，或双击 Start.cmd：

```powershell
Set-Location E:/CodexData/scratch/2026-10-21/practice-autofill
.\Start.cmd
```

启动检查后选择 1 打开网页、2 使用终端，回车默认终端。原 Python 入口默认仍是终端菜单。

```powershell
# 网页操作，自动打开本机默认浏览器
.\Start.cmd --web
# 不自动打开网页，手动访问终端输出的地址
.\Start.cmd --web --no-open
# 固定控制台端口（占用时请换端口，或用默认 0 自动分配）
.\Start.cmd --web --web-port 8787
# 使用 TOML 作为本次启动值
.\Start.cmd --web --config config.example.toml
# 终端操作，不打开控制台
.\Start.cmd --menu
# 保留原 Python 方式
.\.venv\Scripts\python.exe -m practice_autofill --web
```

网页控制台只绑定 127.0.0.1，默认动态端口；此端口与答题浏览器的 CDP 9527 是两个用途不同的端口。控制台页面可以在普通浏览器打开，答题目标浏览器按“浏览器”页的配置选择。没有安装全局软件、改 PATH、引入前端依赖或远程字体。

关闭网页标签页不会结束后台任务；可重新打开同一地址查看当前状态。关闭服务终端或 Ctrl+C 会请求停止本次任务。终端与网页分别启动时，临时配置不共享；请勿让两个实例同时操作同一答题页面。

## 页面与流程

1. **API 配置**：设置现有 base_url、模型、超时、重试、调用间隔、输出上限与 Key。每项都附有作用和范围说明。Key 使用密码框；已保存 Key 只显示是否设置，不返回其值。留空保留；保存不测试接口、不产生 API 费用。
2. **浏览器**：选择自动、连接已有实例或启动专用新实例。检测结果区分“路径存在”和“实际启动验证”；检测不是启动。点击“使用此路径”仅填入草稿，还需应用。显式配置失败不会静默切换。
3. **答题与节奏**：批量/逐题、批大小、字符预算、失败回退；慢/正常/快/自定义网页节奏；自动回填、先清空、外传确认和页面就绪等待。高级折叠项配置现有通用 CSS 选择器。所有修改仅当前控制台有效，不写 TOML。
4. **练习工作台**：选择自动完成当前页、只读检查、单题验证或本地演练，按“开始处理”。需要新实例时可填写隐藏的页面 URL；连接已有浏览器不会依据该地址跳转。单题验证与只读检查沿用既有超星 CDP 入口。
5. **交互区**：手动登录后按“登录完成，继续”；有多个标签页时按记录中的编号选择。逐题模式若要求确认，输入 y 回填。可人工翻页，再按“重新扫描 / r”。每个回应只作用于当前提示，旧回应会拒绝。
6. **运行记录与进度**：显示真实脚本输出、题目预览和回填结果。识别数针对最近一次扫描；核验/人工/跳过等为本任务累计数据，包含重新扫描。不展示模型推理字段，不自动提交。

默认快速求解、自动回填、先清空后填写、外传默认允许；正常网页节奏保持原速。可在设置页切换。快模式减少重复整题读取，保留清空核验、控件重定位与最终回读。

## 本地演练

在工作台选择“本地演练”，点开始。它使用项目已有测试页和模拟模型，启动专用新实例；不需要 Key，不消耗 API 额度。浏览器打开后，在交互区点击继续。测试页覆盖单选、多选、多空、textarea、contenteditable、iframe 编辑器、延迟题及嵌套 iframe，图片题按既有规则跳过。

没有可用浏览器时，请到浏览器页检测；安装或下载浏览器仍需通过原启动器明确确认，不会由网页偷偷执行。

## 停止、配置清除与隐私

- “停止任务”请求协作停止。在待输入、扫描或填写检查点结束；正在等待的网络请求可能需要等到返回或超时，不会杀死占用端口的进程。已经发生的网页写入不会撤销。附加的用户浏览器保持打开；专用实例按原流程关闭并保存登录。
- “清除设置”只恢复启动时的 API 参数并移除工具进程的 Key；需输入 CLEAR，默认取消。不会删除文件、缓存、登录资料或其他设置，不修改父终端环境。
- Key 和新实例 URL 只留在运行所需的进程内存中。控制台不写 HTTP 访问日志；API 状态响应不返回 Key；页面输出对 Key 和 URL 查询参数脱敏。题目/答案和登录资料仍按现有规则存储在 runtime/，它们是本地私密数据。
- 控制端仅接受本机 Host，写操作还检查同源、会话 Cookie 和独立请求令牌。它是本机工具，不提供公网部署或多人账户功能。前端以纯文本展示题目与日志，不执行其中的 HTML/脚本。
- 本地演练通过不等于真实 API、真实网页回填或任意网站适配已经验证。

## 排查

| 现象 | 处理 |
| --- | --- |
| 网页打不开 | 保持服务终端运行，使用输出的准确 127.0.0.1 地址；固定端口占用时换端口或省略 --web-port。 |
| 连接已断开 | 检查服务是否退出；刷新原地址或重新启动，不会靠刷新重发任务。 |
| 无法连接普通 Edge 窗口 | 使用专用新实例，或由你手动启动开放本机 CDP 端口的独立实例；普通窗口不会自动具备 CDP。 |
| API Key 未设置 | 在本次控制台 API 页输入，或在启动它的终端设置环境变量；其他终端的临时变量不会自动传来。 |
| 停止仍显示等待 | 等当前模型请求返回/超时，工具再在安全点结束；不会强制杀浏览器。 |
| 设置未生效 | 点击对应页面“应用”；运行中不允许修改设置。重启后恢复 TOML/默认值是预期行为。 |
| 未识别题目 | 检查独立站点适配路径或高级通用选择器；遇到登录或限制先在浏览器人工处理。 |

## 实现与验证

### 诊断日志

运行记录新增本地显示时间、失败提示强调和批次路径（例如 b0001_l_r）。开始操作时显示运行编号；本地 `runtime/events.jsonl` 采用追加 JSON 行，包含 UTC 时间、运行编号、info/warning/error 级别及以下白名单字段：

- 每次模型调用：工具生成的 request_id、单题/批量、题数、请求数据字符数（不包含系统提示词）、max_tokens。
- 接口结果：HTTP 错误状态、规范化 finish_reason、输入/输出/总 token 用量、接口提供时的 reasoning_tokens、最终内容字符数、请求耗时。没有提供的用量字段省略，不按零处理。
- 恢复过程：批次及深度、尝试序号、校验问题类别、通过/未知/待恢复数量、拆分原因、逐题回退与重试等待。
- 求解统计：模型调用尝试总数（含批量、重试及单题回退）、拆分数、回退数、可靠/未知/未返回答案数量。此统计不等同网页已经填写完成，网页仍须单独回读核验。

`finish_reason=length` 表示接口报告生成长度受限；context_limit 表示 HTTP 接口报告上下文/请求过大；insufficient_system_resource 表示推理服务资源不足；aborted 表示生成被中断。它们不可混作同一种根因。脚本保留既有恢复策略，但会显示为何在 1/3 时直接拆分。missing/other 表示字段缺失或未识别，不能据此断言预算不足。

日志不记录模型原始正文、推理文本、题干/答案、Key、URL、Cookie 或原始错误响应，也不持久化提供方的请求标识。request_id 是本工具生成的关联编号。网页预览题目/答案仍按原有功能在本机显示，答案缓存仍按原约定保存。

若报告故障，可提供对应 run_id 的诊断行，先自行检查是否包含其他工具追加的敏感内容。旧版本未记录的 finish_reason 和 token 用量无法事后恢复；更新后需重新启动工具，未来实际请求才能产生这些诊断。不会为了补日志清缓存或自动重发付费请求。

web.py 使用标准库本机 HTTP 服务和内存任务状态；web_worker.py 通过 JSON 行协议将现有 CLI 的输出/输入桥接到页面，模型与回填行为继续复用原模块。HTML/CSS/JS 为离线静态资源，不需要构建工具。

验证命令：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

网页专项为 test_web.py 与 test_web_browser.py：配置原子校验、密钥不回传、清除范围、同源控制、启动选择，以及真实本地浏览器中的配置、清除、响应式布局、文本注入防护、模拟题回填、交互回应和停止。测试产物保留在 runtime/，不自动清理。
