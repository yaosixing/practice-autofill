# 终端交互与模拟 UI

## 1. 交互方案

运行 `python -m practice_autofill` 或加 `--menu` 进入主菜单。已有带参数命令仍直接运行，不强制进入菜单。`--config` 指定的 TOML 继续只读加载；菜单修改的 API 参数和 Key 仅在当前 Python 进程生效，退出后失效，不持久保存到文件。Key 仍通过 `DEEPSEEK_API_KEY` 传给现有模型模块，不改变模型请求、外传默认允许、清空后填写、默认不提交等业务行为。

主菜单的 `3 / a` 直接进入填写／修改 API 配置，`4 / c` 进入清除确认。子页面用 b 返回上一级、m 返回主菜单、q 退出菜单；配置输入期间回车保留原值。配置字段先存草稿，保存时输入 yes 确认，其他输入默认取消保存。未保存的草稿在返回主菜单、退出或 Ctrl+C 后丢弃。字段编辑处 b 只取消该字段输入，仍回配置页。

清除范围经用户确认：API 参数恢复为菜单启动时的值（包含从指定 TOML 加载的值），并移除当前 Python 进程的 Key。不修改配置文件、父终端环境变量、浏览器登录资料、题目答案、处理进度或日志。必须输入大小写完全一致的 CLEAR，回车和其他输入均取消。

配置缺失或损坏时可重试、显式选择仅本次用默认配置或退出，原文件不被覆盖。缺少 Key 时提示进入 API 配置；非数字、越界、NaN、无效地址等不会应用。失败结果页隐藏原始异常，可返回修正。执行中 Ctrl+C 中断当前任务并返回结果页，已写入网页的内容不自动撤销。题目回填等原业务提示仍按命令规则执行，例如单题页 q 结束本次任务，再进入操作结果页；URL、登录等待和标签页选择支持 b/m/q 停止任务并返回结果页，随后可返回上一级、主菜单或退出。

终端支持时标题为青色；设置 NO_COLOR 或输出重定向时使用纯文本。所有状态同时有文字标记，颜色不承载独有含义。Key 始终显示为“已设置，隐藏”，不展示首尾字符；隐藏输入不可用时拒绝明文降级。界面不记录 Key、URL 或原始错误。保存并不等于 API 连通性已验证。

### 跳转关系

```text
主菜单 ── 3 / a ──> API 配置 ── 1–7 ──> 字段输入
  │                    ↑                   │
  │                    └── 有效值/回车/b ──┘
  │                    │
  │                    s → yes → 保存结果 → b 回配置 / m 主菜单 / q 退出
  │                    b / m → 丢弃未保存草稿，回主菜单
  │
  ├── 4 / c ──> 清除确认 ── CLEAR ──> 清除结果
  │                  └── 回车/其他/b/m → 取消，回主菜单
  ├── 1 / 2 ──> 执行中 ──> 操作结果 ── b/m 主菜单 / q 退出
  ├── 5 ──> 更多操作 ── 1 单题 / 2 本地服务 / 3 模拟测试 / 4 独立浏览器
  │              └── 执行结果 ── b 更多操作 / m 主菜单 / q 退出
  ├── 6 ──> 答题模式 ── s 保存当前进程 / b 放弃 / m 主菜单 / q 退出
  ├── 7 ──> 浏览器检测结果 → 浏览器设置 ── s 保存 / b 放弃 / m 主菜单 / q 退出
  └── 0 / q ──> 退出
```

操作执行前显示状态，完成、失败或取消后均显示结果页。自动批量操作不重新增加逐题确认或外传询问；沿用当前配置。单题验证仍预览确认，不等同正式自动模式。本地服务器前台运行，Ctrl+C 停止；模拟测试需要在另一个终端先启动本地服务。

## 3. 修改位置

- `practice_autofill/menu.py`：完整菜单实现、配置草稿、隐藏输入、二次确认、结果页与导航。无文件写入和删除操作。
- `practice_autofill/cli.py`：默认主菜单和 `--menu`；保留原参数模式；复用相同业务函数；URL 与标签页输入校验、取消返回。
- `practice_autofill/config.py`：提取可复用的 validate_config，供 TOML 与内存草稿共用；拒绝非有限时间参数。
- `tests/test_menu.py`：交互与参数测试。

菜单没有新增第三方依赖或修改数据库结构。新增快速模式使用独立批量协议和版本化缓存；历史 SOURCE.md 不再更新。

## 4. 验证清单

| 场景 | 预期 |
| --- | --- |
| 首次配置 | 主菜单显示未设置，隐藏输入 Key，保存后状态更新 |
| 修改配置 | 显示正在修改，其他字段保持，保存仅当前进程 |
| 取消输入 | 字段 b 返回配置，配置 b/m 丢弃草稿，q 退出 |
| 无效输入 | 菜单、数值、URL、标签页重试；错误内容不直接回显 |
| 取消保存 | 回车默认取消，原参数和 Key 不变 |
| 清除确认 | 输入 CLEAR 才恢复启动参数并移除当前进程 Key |
| 取消清除 | 回车、其他输入或返回均不清除 |
| 清除后 | Key 未设置，可再次配置；文件与业务数据保留 |
| 缺失配置 | 重试、显式默认或退出，原文件不覆盖 |
| 执行失败 | 结果页可返回、主菜单或退出，不显示原始异常 |
| Ctrl+C / EOF | 取消当前编辑或退出；不保留未保存草稿 |
| 隐藏输入不可用 | 拒绝明文降级，不暴露 Key |
| 原命令兼容 | --run-cdp --auto-fill 等仍直接执行业务路径 |

测试仅使用本地模拟页面和模拟模型，不验证真实 Key 有效性，不执行真实网页答题或提交。

## 网页选填节奏页

主菜单新增 `[8] 网页选填节奏：快（题间 0s / 控件 0s）`。跳转为：主菜单 8 → 预设说明 → 设置页 → s 保存结果 / b 放弃 / m 主菜单 / q 退出。

```text
========================================================
选填节奏设置
========================================================
[1] 模式（1 慢 / 2 正常 / 3 快 / 4 自定义，亦可中文或英文）：fast
[2] 自定义题间等待秒数：0.5
[3] 自定义控件处理间隔秒数：0.1
[s] 保存  [b] 放弃返回  [m] 主菜单  [q] 退出
选填节奏设置 >
```

预设说明：慢 1.5s/0.35s，正常为原速且无额外等待，快减少重复整题读取且无额外等待。自定义字段仅在 custom 模式生效，范围 0–30 秒，支持小数；无效输入不应用。保存仅当前进程有效；API 清除范围不变。控件间隔包含清空检查和回填步骤，必要的定位与回读验证始终保留。
