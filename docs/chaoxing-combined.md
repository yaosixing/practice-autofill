# 超星组合材料题适配

## 已观察的结构

2026-10-24 在用户当前 work/dowork 页面只读检查到：共 4 个材料容器，每个容器有 1 道单选子题；两份材料包含表格。所有选项都没有原普通选择题的 answerBg/role 属性组合，因此旧规则无法匹配。

结构依据为：

```text
.questionLi[id]                  共用材料容器
  .mark_name                    材料及可选表格
  .readComprehensionQues
    .reading_answer[itemid]     子题；同一材料可有多道
      .reader_answer_tit
        .read_type              明确题型标签
      .stem_answer
        div.clearfix.hoverDiv.workTextWrap
          .num_option           单选标记与字母
          .answer_p             选项正文
```

现场仅核实了组合单选；其既有 addChoice 函数支持再次点击取消选择，以 check_answer 和 aria-checked 更新状态。只读取了函数的状态处理语句，没有执行该函数。实现不修改真实页面的角色、样式或隐藏字段来伪造答案。

## 实现规则

- 默认 selectors/chaoxing.work.toml 同时选择普通题与组合子题，不把组合材料容器误当成一整道选择题。
- 每个子题题干包含完整材料、表格与本子题提示，不夹带兄弟子题。表格逐行、以 ` | ` 分列；MathML/TeX 文本规则沿用原实现。
- 子题标识由材料 id 与子题 itemid 组合。不同材料可使用相同子题 id；相同材料的重复 id 会在定位时拒绝。
- 无 role 的选项仅在组合题内启用，要求明确的单选/多选题型标签、选项标记、字母、文本及已配置处理函数全部一致。不根据外观或选项数量猜题型。
- 检查所有选项标记数量，防止部分控件漏匹配后仍填写；混入文本框、未知控件、隐藏/禁用选项等情况继续停止或转人工。
- 保留清空、重定位及回读逻辑。材料、表格、选项、文档或唯一性变化都会使旧目标失效；不会因同字母选项而串填其他子题。
- 材料或子题包含图片、canvas、未知 SVG 时仍转人工；没有新增视觉模型、翻页或提交功能。

## 使用与验证边界

继续使用默认 selectors/chaoxing.work.toml。若手动指定了其他选择器文件，需切回默认文件；不要仅扩宽选择器而取消题型与状态核验。

网页端：先结束正在等待重新扫描的旧任务，再点“开始处理”创建新任务；原运行进程已加载旧 JS，仅发送 r 不会更新。命令行用户重新启动脚本。无需清理登录资料或答案缓存。

验证记录：

- runtime/validation-combined-live.json：真实页面只读提取/定位，4 道 single、4 道成功定位、零跳过，所有选项状态保持不变。未验证真实网站回填。
- fixtures/chaoxing_combined.html：完全虚构的材料、表格、同材料多个子题、不同材料重复子题 id、组合单选与多选。仅本地执行清空、回填及重复填写，提交计数必须为零。
- tests/test_chaoxing_combined.py：上下文/表格保留、题内定位、材料变化停止、重复标识停止、图片转人工、未知题型和漏选项保护。

不承诺适配其他未观察的组合题、超星填空或任意新版页面。
